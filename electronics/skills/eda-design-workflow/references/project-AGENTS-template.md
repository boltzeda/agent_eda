# Circuit project instructions

Use Agent-EDA's `eda-design-workflow` skill. Keep this file about this circuit's
engineering constraints, not about developing the Agent-EDA application.

- Requested deliverable: fill from the user's request.
- Electrical requirements and operating conditions: record confirmed values.
- Approved parts/packages and pin-map evidence: link project documents.
- Board, connector, fabrication and mechanical constraints: distinguish sourced
  requirements from explicitly authorized provisional assumptions.
- Artifact locations and required verification: identify schematic/ERC,
  simulation, placement and routing/DRC reports as applicable.
- Explicit exceptions: record the user instruction and unverified consequences in project notes.

Preserve existing project instructions. Do not treat this template's placeholders
as approved constraints, and do not mark a stage complete without evidence.
